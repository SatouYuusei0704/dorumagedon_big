# features/

機能ごとにフォルダを分け、担当者ごとに作業範囲が衝突しないようにしています。

| フォルダ        | 内容                                      | 担当 |
| --------------- | ----------------------------------------- | ---- |
| `avatar/`       | Mii風アバター作成・ドット絵描画（Canvas） | A    |
| `encounter/`    | 位置情報取得・すれ違い判定                | B    |
| `items/`        | 果物アイテムの交換・図鑑                  | C    |
| `notification/` | Supabase Realtime による通知・演出        | D    |

- 各機能のコンポーネント・hooks・ロジックはそのフォルダ内に置く
- 複数機能で使う UI は `src/components/ui/`、共通処理は `src/lib/` へ
